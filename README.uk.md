# Omarchy Internet Route Switcher

Плагін для Omarchy Shell і CLI-утиліта, що дозволяють вибрати, через яке з’єднання NetworkManager віддавати перевагу основному маршруту: Ethernet чи Wi‑Fi.

Плагін створений на основі вбудованої мережевої панелі Omarchy та додає в неї перемикач **INTERNET ROUTE**. Ethernet і Wi‑Fi залишаються підключеними, тож локальні маршрути до їхніх мереж продовжують працювати.

## Режими

| Режим | Поведінка |
| --- | --- |
| `Auto` | Ethernet отримує метрику маршруту 100, Wi‑Fi — 600. Обидва можуть надавати маршрут за замовчуванням, але перевага в Ethernet. |
| `Ethernet` | Ethernet отримує метрику 100. Для Wi‑Fi встановлюється `never-default`, тож він залишається доступним для локальної мережі, але не надає маршрут за замовчуванням. |
| `Wi-Fi` | Wi‑Fi отримує метрику 50, Ethernet — 2000. Обидва залишаються придатними для маршруту за замовчуванням, але перевага в Wi‑Fi. |
| `Both` | Нові з’єднання розподіляються між Ethernet і Wi‑Fi. Відповіді йдуть тим самим шляхом, що й початкове з’єднання. Це не об’єднує канали для одного завантаження. |

Налаштування застосовуються до **всіх збережених профілів NetworkManager типу Ethernet і Wi‑Fi**. Виберіть `Auto`, щоб повернути стандартні значення цієї утиліти. Поточні власні метрики маршрутів і значення `never-default` у цих профілях буде замінено.

## Вимоги

- Omarchy Shell із системою плагінів і командою `omarchy`
- NetworkManager із `nmcli`
- `nftables`, `iproute2` і `pkexec` для режиму `Both`
- Bash

## Встановлення

У клоні цього репозиторію виконайте:

```bash
./install.sh
```

Скрипт копіює CLI в `~/.local/bin/`, встановлює системний root-owned помічник маршрутизації та NetworkManager dispatcher, перевіряє маніфест, встановлює плагін із GitHub під ID `maksymturskyi-del.network-route-switcher`, активує його й перезапускає Omarchy Shell. Під час встановлення потрібен `sudo`. Вибір `Both` відкриє запит Polkit для дозволу налаштувати маршрути. Для використання CLI каталог `~/.local/bin` має бути у змінній `PATH`.

Щоб встановити плагін командою Omarchy напряму:

```bash
omarchy plugin add https://github.com/maksymturskyi-del/omarchy-network-route-switcher.git --enable
```

Після цього встановіть CLI і системний помічник із клонованого репозиторію, не додаючи плагін вдруге:

```bash
./install.sh --skip-plugin
```

## CLI

```bash
omarchy-internet-route          # Показати вибраний режим
omarchy-internet-route Auto
omarchy-internet-route Ethernet
omarchy-internet-route Wi-Fi
omarchy-internet-route Both
```

Режим зберігається у `~/.config/omarchy/network-route.mode`. NetworkManager може повторно застосувати параметри профілю після перепідключення.

## Керування клавіатурою

Рядок маршруту підтримує навігацію панелі: `j`/`k` — перехід між секціями, `h`/`l` — вибір режиму, `Enter`/`Space` — застосування.

## Примітки

- Налаштування змінюють профілі NetworkManager для IPv4 та IPv6.
- `Both` розподіляє нові з’єднання між двома підключеними каналами через conntrack і policy routing. Обидва канали мають мати IPv4-шлюз. IPv6 балансується, якщо обидва мають IPv6-шлюзи. Якщо активний третій маршрут за замовчуванням (наприклад, VPN), `Both` відмовиться вмикатися.
- У `Both` можна вибрати `Manual`: типовий список показує програми з відкритими вікнами та групує їх за executable. В `Advanced · PID` спочатку показані ці програми за PID, а нижче — решта процесів користувача. Уже відкриті з’єднання залишаються на старому шляху, доки програма не перепідключиться. `Auto` продовжує розподіляти нові потоки автоматично.
- Список має обмежену висоту й фільтр за назвою; у розширеному режимі доступний пошук за PID. Авторизація Polkit для активної сесії тимчасово кешується (зазвичай на п’ять хвилин), щоб не питати пароль після кожного кліку.
- `Both` не об’єднує канали для одного потоку; різні з’єднання можуть іти різними каналами.
- Репозиторій містить змінену копію мережевої панелі Omarchy. Атрибуцію та умови ліцензії наведено у [NOTICE](NOTICE).
- Це незалежний спільнотний плагін, не пов’язаний з Omarchy і не схвалений командою Omarchy.
